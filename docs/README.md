# docs/

Everything here is meant for GitHub and for the class submission.

- `project_scope.md` — the framework, corpus, and decision log for the
  whole project (mirrored from the Claude Project — that's the master copy).
- `eval_results.md` — the 15-question evaluation set (single-fact,
  cross-year, cross-company, unanswerable), ground-truth answers, and the
  logged results (retrieved chunk / score / generated answer / faithfulness)
  for all 4 conditions (fixed-size vs. semantic × basic vs. MMR retrieval).
- `demo_script.md` — talking points for the required demo video.
- `comparison_report.md` — fixed vs. semantic chunking comparison +
  reranking impact analysis — the core Week 2 deliverable — *not yet created*.
